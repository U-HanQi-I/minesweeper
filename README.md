# 扫雷 (Minesweeper)

一个纯前端、单文件的扫雷小游戏，使用原生 HTML + CSS + JavaScript 实现，无需任何依赖、无需构建，打开即玩。

## 🎮 在线试玩

> https://U-HanQi-I.github.io/minesweeper/

## ✨ 功能特性

- **经典规则**：9×9 棋盘、10 颗雷（初级难度）
- **首次点击安全**：雷在第一次点击后才埋设，且会避开首点及其周围 8 格，保证第一步永远落在空白区
- **空白扩散**：翻开数字为 0 的格子时，自动向周围扩散展开
- **右键插旗**：右键标记/取消旗子，顶部实时显示剩余雷数
- **计时器**：从第一次点击开始计时，胜利时显示用时
- **胜负判定与反馈**：
  - 胜利时自动标记所有雷，显示 🎉 和用时
  - 踩雷时翻开所有未标记的雷、标出插错的旗子（❌）、高亮踩中的雷（红色）
- **重新开始**：一键重开，按钮表情随状态变化（😊 / 😎 / 😵）
- **零依赖**：单个 HTML 文件，无任何外部库或资源

## 🕹️ 操作说明

| 操作 | 效果 |
|------|------|
| 左键点击 | 翻开格子 |
| 右键点击 | 插旗 / 取消旗子 |

## 🚀 本地运行

无需安装任何东西，直接用浏览器打开 `index.html` 即可：

```
双击 index.html
```

或者用任意静态服务器：

```bash
# 任选其一
npx serve .
python -m http.server 8080
```

然后访问 http://localhost:8080

## 🛠️ 技术实现

- **前端三件套**：原生 HTML / CSS / JavaScript，无框架、无构建工具
- **数据结构**：`board` 为二维数组，每格存储 `{ mine, revealed, flagged, adjacent }` 四个状态
- **埋雷算法**：`placeMines()` 排除首点安全区后，用 Fisher–Yates 洗牌随机取雷
- **扩散算法**：`reveal()` 用栈（DFS）实现空白格扩散，旗子会阻挡扩散
- **渲染**：`render()` 全量重绘棋盘；事件通过「事件委托」统一绑定在棋盘容器上
